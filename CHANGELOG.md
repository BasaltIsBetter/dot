# Dot changelog

One section per version, the newest at the top, titled `## [x.y.z] - YYYY-MM-DD`, then `### New`
and `### Fixed`. Written for the people who use Dot: what changes for them, not how it is done.
Pushing the tag `vx.y.z` publishes the version with this section as its notes; the release stops if
the section is missing or empty.
