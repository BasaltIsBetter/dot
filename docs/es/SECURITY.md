# Seguridad

[English](../../.github/SECURITY.md) · [Français](../fr/SECURITY.md) · **Español** · [Português](../pt/SECURITY.md)

Dot ejecuta comandos y modifica archivos a partir de las respuestas de un modelo: una vulnerabilidad
ahí sale cara. Infórmala en privado con
[«Report a vulnerability»](https://github.com/BasaltIsBetter/dot/security/advisories/new) de GitHub,
nunca en una issue ni en una pull request públicas.

Indica la versión de Dot, el sistema, lo que encontraste, cómo reproducirlo y lo que permite; una
pequeña prueba de concepto ayuda. Quita de los registros cualquier clave de API, token o dato
personal.

Solo se mantiene la última versión publicada.
