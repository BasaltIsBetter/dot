# Segurança

[English](../../.github/SECURITY.md) · [Français](../fr/SECURITY.md) · [Español](../es/SECURITY.md) · **Português**

O Dot executa comandos e altera arquivos a partir das respostas de um modelo: uma vulnerabilidade
ali custa caro. Relate-a em particular pelo
[“Report a vulnerability”](https://github.com/BasaltIsBetter/dot/security/advisories/new) do GitHub,
nunca em uma issue ou pull request públicas.

Informe a versão do Dot, o sistema, o que você encontrou, como reproduzir e o que isso permite; uma
pequena prova de conceito ajuda. Remova dos logs qualquer chave de API, token ou dado pessoal.

Só a versão publicada mais recente é mantida.
