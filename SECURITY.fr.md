# Sécurité

[English](SECURITY.md) · **Français** · [Español](SECURITY.es.md) · [Português](SECURITY.pt.md)

Dot lance des commandes et modifie des fichiers à partir des réponses d'un modèle : une faille s'y
paie directement. Signale-la en privé par
[« Report a vulnerability »](https://github.com/BasaltIsBetter/dot/security/advisories/new) de GitHub,
jamais dans une issue ni une pull request publiques.

Donne la version de Dot, le système, ce que tu as trouvé, comment le reproduire et ce que ça permet ;
une petite preuve de concept aide. Retire des journaux toute clé d'API, tout jeton et toute donnée
personnelle.

Seule la dernière version publiée est suivie.
